# 品牌手册：名字与 Logo

> 2026-09-15 二次定案（店面切源站同款后）：名字 **AI充站**，logo **充电 bolt + 充电口**。
> 2026-09-14 首次定案记录保留在文末附录。改品牌前先读一遍。

### 名字调研（当时定「代充」，现已被 AI充站 取代）

### 调研过程

| 候选 | 判断 |
| --- | --- |
| **代充 / DAICHONG** ✅ | 用户指定的方向（"daichong 之类的"）；中文买家搜「XX代充」是**品类词**，站名与搜索词重合，SEO 天然占位；直白说明业务（代客充值） |
| AI Access | 早期占位英文名。问题：与业务（代充）无关联、无中文记忆点、丢掉品类词流量 |
| 充叮 / 叮充 | 造词可注册性更好，但需要教育市场——冷启动阶段品牌词没人搜，浪费最稀缺的品类词位 |
| 充电堡 / 充值站 | 偏「游戏点卡」联想，与 AI 账号/接码的客群气质不符 |

**结论**：店名 **代充**，拉丁词标 **DAICHONG**（og 卡/域名/大小写不敏感场景用）。

### 用法

- 店铺展示名（页头/页脚/元数据）：`代充` —— 在 `buyrelay.config.yaml` 的 `store.name`
- 拉丁词标（og 卡、纯 ASCII 场景）：`DAICHONG`，全大写，字距正常
- 一句话介绍（英）：AI accounts & codes, delivered automatically
- 一句话介绍（中）：AI 账号与接码代充，付款即自动发货

## 二、Logo：闸门 A（Gate A）

### 几何

32×32 viewBox，圆角矩形（rx=7）深绿底，其上两条描边构成一个**开口的 A 形闸门**：

```
┌──────────────┐
│      /\      │   底：var(--pop)    #1C5F45（暗黑 #6FC79E）
│     /  \     │   线：var(--bg)     #F7F5F2（暗黑 #121110）
│    /    \    │   线宽 2.6，圆角端点
│   ──────     │
└──────────────┘
```

三处消费，改图形必须三处同步：

1. `src/components/brand-mark.tsx` —— 页头内联（吃 currentColor/行高）
2. `src/app/icon.svg` —— favicon
3. `scripts/generate-brand-assets.ts` —— og 卡与 apple-touch-icon 的位图重绘

### 语义

A = AI；闸门 = 「通了」——付款即开闸发货。尖顶朝上只有一个方向，没有装饰性
渐变与阴影，暗黑模式下底/线自动互换（token 驱动）。

### 规则

- 最小尺寸 18px（页头），小于 16px 环境直接省略文字只留 mark
- 底色永远用 `--pop` token，不要写死十六进制 —— 暗黑模式靠它翻转
- 与文字组合时：mark 高度 = 文字 cap height，间距 8px
